# Personal Portfolio – Next.js

This is a simple yet professional personal portfolio website built using **Next.js**. It includes essential sections to showcase your profile, projects, and skills, along with a working contact form powered by **Web3Forms**.

## ✨ Features

- Built with **Next.js** and **TypeScript**
- Clean and responsive UI
- Contact form using [Web3Forms](https://web3forms.com/)
- Projects section with associated skills
- Total of **6 pages**
- SEO-friendly structure

## 📄 Pages Overview

- **Home** – Introduction and hero section  
- **About** – A short bio and background  
- **Projects** – Showcasing work along with the skills used  
- **Skills** – List of technical skills  
- **Contact** – Integrated form using Web3Forms  
- **(Optional pages)** – You can add or remove as needed

## 🚀 Getting Started

Follow the steps below to run the project locally:

```bash
# Clone the repository
git clone https://github.com/hassannawaz02/Personal_Portfolio.git

# Navigate into the project directory
cd Personal_Portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
